# Data

Download the [Rice Image Dataset](https://www.kaggle.com/datasets/muratkokludataset/rice-image-dataset) from Kaggle and extract it under this directory.

Expected structure:

```text
data/Rice_Image_Dataset/<class-name>/*.jpg
```

The five class directories are `Arborio`, `Basmati`, `Ipsala`, `Jasmine`, and `Karacadag`. Raw images are excluded from Git.
